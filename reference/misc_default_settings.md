# Get default settings for multi-indicator sigma charts

Get default settings for multi-indicator sigma charts

## Usage

``` r
misc_default_settings(group = NULL)
```

## Arguments

- group:

  Optional settings group. If `NULL`, all groups are returned.

## Value

Native Funnel settings used by
[`misc()`](https://aus-doh-safety-and-quality.github.io/controlcharts/reference/misc.md).
