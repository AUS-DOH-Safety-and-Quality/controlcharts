# controlcharts: Interactive Plotting for Funnel, Sigma, and Statistical Process Control Charts

Generate interactive funnel plots, multi-indicator sigma charts, and
statistical process control ('SPC') charts. Chart calculation and
plotting use JavaScript, allowing dynamic charts without a Shiny server.
For more details see Spiegelhalter (2004)
[doi:10.1002/sim.1970](https://doi.org/10.1002/sim.1970) and Pfadt &
Wheeler (1995)
[doi:10.1901/jaba.1995.28-349](https://doi.org/10.1901/jaba.1995.28-349)
.
